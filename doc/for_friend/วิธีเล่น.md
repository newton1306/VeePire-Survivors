# วิธีเล่น VeePire Survivors (คู่มือฉบับสมบูรณ์)

เกม 2D Action RPG บนบอร์ด **Digilent Nexys A7-100T** — ตะลุย **6 Waves แบบห้องเดี่ยวสี่เหลี่ยม (Single-Room Arena)** ควบคุมด้วย **จอยสติ๊ก 100% (1P / 2P Co-op)** พร้อม **ตัวละครและศัตรูหน้าคนล้วน**, **ระบบเลือกสกินตามลำดับสวิตช์ `SW0–SW3`**, **2 ระลอกย่อยต่อ Wave**, **ปุ่ม `Start` สำหรับ Pause พร้อมแผนผังปุ่มจอย**, **ประตูสไลด์ + ควิซสุ่ม Logic Gate**, **เอฟเฟคล็อคประตู "ปั้ง!" + แบนเนอร์สไลด์ออก**, **วิวัฒนาการแบบไร้ Cutscene**, และ **บอส `Ajarn_V` 3 ร่างงอกจาก Portal พร้อมคำพูดสุดเบียว**

---

## 1. การเลือกโหมดที่หน้าจอเริ่มเกม (Title Screen)

หน้าเริ่มเกมแสดงโลโก้ **`VeePire Survivors`** พร้อมแถบเลือกโหมด (`◄ ... ►`) 2 โหมด:
1. **`MODE: 1P JOYSTICK`** — เล่นคนเดียวด้วย **จอย 1 (USB)**
2. **`MODE: 2P CO-OP JOY`** — เล่นช่วยกัน **2 คนพร้อมกัน!** ใช้ **จอย 1 + จอย 2**

### วิธีควบคุมเมนู & เริ่ม/รีสตาร์ทเกม:
- **หน้า Title / เมนู:** โยกซ้าย/ขวาบน **จอย 1 / จอย 2** เพื่อสลับโหมด แล้วกดปุ่มโจมตีบนจอยเพื่อเริ่มเล่นทันที
- **เมื่อ Victory หรือ Game Over:**
  - กดปุ่มโจมตีบนจอย 1 / จอย 2 → **เริ่มเล่นใหม่ (Retry) ทันที!**
  - โยก **ซ้าย / ขวา** → **กลับหน้า Title เพื่อเปลี่ยนโหมด!**

## 2. การเลือกสกินฮีโร่หน้าคน (`SW0–SW3`, ยึดสวิตช์ตัวบนสุดที่เปิด)

มีฮีโร่หน้าคนทั้งหมด **4 ตัว** แมปตรงกับสวิตช์ `SW0–SW3` (ตรวจสอบจาก `0` ไป `3` — หากเปิดหลายสวิตช์พร้อมกัน **จะยึดสกินของสวิตช์หมายเลขสูงสุดที่เปิดอยู่เพียงตัวเดียว ไม่ผสม**):
- **`SW0` (ตัวเดียว):** PF (ขอบฟ้า)
- **`SW1` (เปิด `SW1`, แม้ `SW0` เปิดด้วย):** PPuen (ขอบเขียว)
- **`SW2` (เปิด `SW2`, เช่นเปิด `SW1` และ `SW2` → ได้ `SW2`):** PPeem (ขอบทอง)
- **`SW3` (เปิด `SW3`, สูงสุดชนะทุกตัว):** PPing (ขอบชมพู)
- *(หากปิด `SW0–SW3` ทั้งหมด → ค่าเริ่มต้นเป็น PF)*

1. เสียบสายจอย USB คู่ เข้าคอมพิวเตอร์ และต่อสาย Micro-USB เข้าบอร์ด Nexys A7 ช่อง **`PROG/UART`**
2. เปิดไฟล์ [`start_joystick.bat`](D:/vivado_pj/DRAGO_NEXUS_V2/start_joystick.bat)
3. เมื่อหน้าจอขึ้น **`USB JOY: ONLINE!`** แสดงว่าพร้อมเล่นแล้ว

| ปุ่มบนจอย | ความสามารถ |
| :--- | :--- |
| **D-Pad / อนาล็อกซ้าย** | เดิน 8 ทิศทาง (2 ความเร็วในโหมด Analog) + เลือกตัวเลือกใน Logic Gate Quiz |
| **ปุ่ม 2 (`O`) / ปุ่ม 3 (`X`) / `R1`** | **3-Hit Melee Lunge-Snap Combo!** พุ่งดูดระยะใกล้ (`≤72 px`) + คอมโบ 3 จังหวะ (จังหวะ 3 ปล่อย 360° Nova!) + ยืนยันคำตอบ Quiz |
| **ปุ่ม 4 (`[]`) / `L1`** | **Shadow Dash** (พุ่งเร็ว + อมตะชั่วคราว) |
| **ปุ่ม 1 (`^`) / `L2` / `R2` (กดค้าง)** | **Chrono-Shift** (ชะลอเวลาศัตรู/กระสุน/เพลง BGM) |
| **`START`** | **Pause / Resume** — หยุดเกมชั่วคราว พร้อมขึ้นรูปจอยชี้บอกว่าปุ่มไหนทำอะไร |

## 4. ระบบด่านห้องเดี่ยว + 2 Sub-waves + ประตูสไลด์ + ควิซ Logic Gate

- **Single-Room Arena:** แต่ละระลอกจะเห็นเฉพาะห้องสี่เหลี่ยมของด่านนั้น รอบนอกห้องเป็นสีดำสนิท
- **2 Sub-waves ต่อ Wave:** เคลียร์ศัตรูหน้าคนชุดแรกแล้วจะมีกองเสริมชุดที่ 2 เกิดต่อทันที (Wave 1 = `6+6` ตัว จนถึง Wave 5 = `14+14` ตัว) เพื่อความมันส์ในการกดคอมโบ
- **ไอเทมฟื้นพลัง:** ตัดเห็ด/กล่องเสบียงออกทั้งหมด เหลือเฉพาะ **หัวใจ (`♥`)** และ **Gem ฟ้า**
- **วิวัฒนาการไร้ Cutscene:** เมื่อเก็บ Gem ฟ้าครบเกณฑ์ ตัวละครจะอัปเกรดพลัง/Companion/Orbit Swords ต่อเนื่องทันที **ไม่มี Cutscene คั่นจังหวะ**
- **เคลียร์ด่าน → ลูกศรกระพริบ → ควิซ Logic Gate → ประตูสไลด์:**
  1. เมื่อกำจัดศัตรูหน้าคนทั้ง 2 ชุดใน Wave ครบ จะมี **ลูกศรเด้งกระพริบ (`>>>`)** ชี้ไปที่ **ประตูสไลด์** ทางขวาของห้อง
  2. เมื่อเดินไปที่ประตู จะขึ้นหน้าต่างสุ่มถาม **สัญลักษณ์ Logic Gate** (`AND`, `OR`, `NOT`, `NAND`, `NOR`, `XOR`) พร้อม 4 ตัวเลือก — **ต้องตอบให้ถูกเท่านั้นประตูจึงจะสไลด์เปิด!**
  3. เมื่อเดินผ่านประตูเข้าห้องใหม่ จะเกิดเอฟเฟค **ล็อคประตูปั้ง! (`DOOR LOCKED! PANG!`)** โดยไม่หยุดเกม จากนั้นแบนเนอร์ **`WAVE X`** จะขึ้นกลางจอแล้วสไลด์ออกก่อนเริ่มระลอกใหม่

## 5. ด่านสุดท้าย (Wave 6): บอส `Ajarn_V` 3 ร่างงอกจาก Portal

- ด่านสุดท้ายพบกับบอส **`Ajarn_V`** ซึ่งต้องปราบให้ครบ **3 ร่างต่อเนื่อง**:
  1. **ร่างที่ 1 (`Ajarn_V_1`, 40 HP):** เมื่อจัดการได้ จะเกิดเอฟเฟคระเบิดตาย + คำพูดเบียว **`MY SEAL BREAKS AWAKEN PHASE 2!`** แล้วเปิด **Portal** งอกร่างที่ 2 ออกมา
  2. **ร่างที่ 2 (`Ajarn_V_2` Iron-Arm, 55 HP):** โจมตีด้วยกระสุนและเลเซอร์ เมื่อจัดการได้ จะขึ้นคำพูดเบียว **`ABYSS CALLS I AM INEVITABLE!`** แล้วเปิด **Portal** งอกร่างสุดท้ายออกมา
  3. **ร่างที่ 3 (`Ajarn_V Thanos`, 85 HP):** ร่างสุดยอด ปล่อย Infinity Barrage, Hyper-Laser, อุกกาบาต และเรียกลูกน้อง เมื่อจัดการได้จะขึ้นคำพูดเบียว **`MY INFINITY SHATTERS!`** จึงจะเข้าสู่หน้าจอ **`VICTORY!`**
