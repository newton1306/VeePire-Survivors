1. พจนานุกรมศัพท์เทคนิคฉบับคนทั่วไป (อ่าน 1 นาทีเข้าใจเลย!)

คำศัพท์ในสไลด์ความหมายภาษาคนทั่วไป (เอาไว้เข้าใจและอธิบายอาจารย์ได้)
FPGA (Nexys A7-100T)ชิปที่แปลงตัวเองเป็น "วงจรอิเล็กทรอนิกส์" ตามโค้ดที่เราเขียน ทุกส่วนทำงานพร้อมกันแบบฮาร์ดแวร์ล้วนๆ
Pure Verilog (No MicroBlaze)เขียนโค้ดสร้างวงจรเกมเอง 100% ไม่ได้แอบเอา CPU สำเร็จรูปมาใส่แล้วเขียนภาษา C
VGA 640×480 @ 60 Hz (12-bit)สายต่อจอภาพสีน้ำเงิน แสดงผลขนาด 640×480 จุด วาดใหม่ 60 ภาพ/วินาที ใช้ได้ 4,096 สี
VBlank Updateจังหวะพักเสี้ยววินาทีหลังวาดจอเสร็จ 1 ภาพ เราขยับตัวละครเฉพาะช่วงนี้ ภาพจะได้ไม่ขาดครึ่งจอ
Debouncer (5 ms)ตัวกรองสัญญาณปุ่มกดบนบอร์ด (เวลาคนกด 1 ครั้ง หน้าสัมผัสโลหะมันสั่น จึงต้องกรอง 5 มิลลิวินาที)
BRAMหน่วยความจำขนาดเล็กบนชิป FPGA ใช้เก็บรูปหน้าตัวละคร แผนที่ห้อง และโน้ตเพลง 8-bit
FSM (Finite State Machine)แผนผัง "สถานะของเกม" เช่น หน้าเริ่ม → เล่น → Pause → ตอบควิซ → บอส → ชนะ/แพ้
Joystick Bridge (UART)โปรแกรมบนคอมพิวเตอร์ที่ทำหน้าที่เป็น "ล่าม/สะพาน" อ่านจอย USB คู่แล้วส่งผ่านสายเข้าบอร์ด FPGA
